# مواصفات الصفحات — Page Specs
## كل شاشة: الغرض · البنية · الحالات · التنقل

> **الغرض:** المرجع الحرفي لبناء ومراجعة كل صفحة. البنية الموصوفة هنا هي العقد — أي انحراف عنها في الكود هو عيب يُصلح أو قرار يُوثّق هنا أولًا.
> **الاصطلاح:** الأقسام مرقمة من أعلى الصفحة إلى أسفلها. «الحالات» تعني تقلبات الشاشة. المصطلحات التقنية بلغة CSS/TSX موجودة لتوجيه المطور مباشرة.

## B. التطبيق — الغلاف المشترك

### B-0 · App Shell (كل مسارات `/app/*`)

**الغرض:** الإطار الموحّد: شريط علوي (علامة + بحث/أمر + لغة + ثيم + تنبيهات + دخول إعدادات) وقائمة جانبية ثلاثية المجموعات.

- **الأوضاع:** هاتف = drawer + شريط سفلي بخمس وجهات · تابلت = rail قابل للتوسيع · سطح مكتب = موسّع قابل للطي (يُحفظ في localStorage).
- **اللوحة الداكنة المركزة:** مسارات البوابات (`chat/code/analyze/explore`) ترسم على canvas داكن مخصص — `[data-focus-canvas]`.
- **لوحة الأوامر:** ⌘K تبحث في الـ15 وجهة (React state + تصفية label).

## C. بوابات الخدمات (ask · code · analyze · explore)

### C-0 · بوابة الخدمة الموحدة (ServiceWorkspace)

مصدر البناء: `src/components/universal/service-workspace.tsx` · البيانات: `src/lib/universal-content.ts`.

| # | القسم (معرّف) | المحتوى | الحالة/السلوك |
|---|---|---|---|
| 1 | `service-nav` | روابط سياقية (تعلّم/المكتبة/العودة لمساحتي) | حسب الخدمة |
| 2 | الترحيب | Eyebrow + شارة + عنوان متدرج + ليد + «جلسة جديدة» | ثابت |
| 3 | `service-toolbelt` | 3 بطاقات أدوات مختارة بأيقوناتها + تلميح «تتغير الأدوات حسب طلبك» | `aria-pressed` · متعدد |
| 4 | بطاقتا التنفيذ | «موجّه» / «سريع» بجمل كاملة لا كلمات | تبديل فردي |
| 5 | الملقّن | eyebrow + «ابدأ من مقصدك» + حبتا إتاحة معنونتان + CTA | آلة الحالات §4 |
| 6 | المسار الرباعي | «كيف سيعمل منسج؟» 01–04 بخط واصل | يقلب إلى `is-complete` |
| 7 | ملاحظة الثقة | حبة متقطعة + درع نعناعي | ثابت |
| 8 | البدايات السريعة | 3 بطاقات + تلميح | `quickFill` يعبيء الملقّن |
| 9 | من مكتبتك | عنصران + تلميح | روابط للمكتبة |

**البيانات لكل خدمة** (`universal-content.ts`): `eyebrow` · `label` · `description` · `starters[3]` · `outputTitle`. أدوات كل خدمة معرّفة في المكوّن (`serviceTools`) بأيقونات مخصصة:

| الخدمة | أدوات العمل (أيقونات) |
|---|---|
| **اسأل** | مساحة نص (FileText) · إدخال صوتي (Mic) · عصف ذهني (Brain) |
| **برمج** | طرفية (Terminal) · مراجعة عين (Eye) · تتبع خلل (Bug) |
| **حلّل** | جدول (Table) · رسم بياني (ChartNoAxesCombined) · تحقق (ShieldCheck) |
| **استكشف** | بوصلة (Compass) · شبكة معارف (Network) · رسم مسار (Route) |

**العقد المعلّق (الأولوية الأولى):** ربط اختيار الأداة والأسلوب بمصفوفة interaction-logic.md — البنية المرئية جاهزة والمنطق معطّل.

## D. المساحات النطاقية (learn · research · create)

مساحات منجزة بمركّب `domain_workspace` عبر سجل الخدمة. لكل منها بنية متخصصة (مسارات فصول/خطط بحث/موجزات إنشاء) تشترك في آلة الحالات الجوهرية ذاتها. مواصفاتها التفصيلية تُستكمل عند أول تعديل لها — قاعدة التوثيق: لا تعديل قبل توثيق بنيتها الحالية هنا.

## G. طبقة التشغيل (اليتيمة حاليًا)

صفحات منجزة وظيفيًا على بيانات mock، لكنها خارج التنقل — انظر known-issues.md · KI-1.

| الصفحة | البنية | الروابط الداخلية |
|---|---|---|

| **G-3 الاستخدام والتكلفة** | اتجاه يومي + رصيد مختلط + تفصيل أبعاد | ↔ الفوترة |
| **G-4 الفوترة** | رصيد + خطة + حدود إنفاق صلبة + دفع + تعبئة محاكاة | ↔ الاستخدام |
| **G-5 الفريق والأدوار** | أعضاء + أدوار وصلاحيات + دعوات | **صفر روابط داخلية** |
| **G-6/G-7 المهارات والأدوات** | كتالوجان مرتبطان | تبادل بينهما |
