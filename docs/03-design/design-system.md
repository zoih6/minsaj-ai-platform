# نظام التصميم — Design System v2
## «النول» · هوية منسج البصرية الموحّدة

> **الغرض:** العقد البصري الذي تُبنى عليه كل شاشة. أي قيمة هنا (لون، خط، مسافة) تُطبّق من طبقات CSS المرجعية ولا تُعاد اختراعها محليًا داخل مكون.
> **مصدر الحقيقة في الكود:** `src/app/styles/universal/*` عبر المدخل `src/app/universal.css`.
> **إعادة البناء (W-DS):** هذا الملف يبقى الملخص المعتمد على مستوى المنتج؛ الشامل الجديد — التشخيص الجنائي، الطبقات، القواعد التنفيذية، وبروتوكول QA ذو البوابتين — في [`reconstruction/`](./reconstruction/DESIGN-SYSTEM-RECONSTRUCTION.md) (بالإنجليزية بقرار المالك). عند أي تعارض **بعد اعتماد W-DS**: الوثائق الجديدة تحكم، ويُحدّث هذا الملف في الكوميت نفسه.

## 1. المبدأ التوجيهي

النظام يقوم على استعارة النول: **سطوح هادئة تعرض المحتوى، وخيوط ملوّنة دقيقة تشير إلى الخدمات**. النتيجة واجهة تشبه مساحة عمل حرفي ماهر — دقيقة الإيقاع، دافئة المادة، بلا ضجيج بصري. كثافة اللون منخفضة عمومًا (70% محايد / 20% ثانوي / 10% لهجة) واللون المشبع يظهر في الحدود والخيوط والنصوص الدقيقة، لا في المساحات الكبيرة.

## 2. الألوان — التوكنز

الطبقة المرجعية: `foundations.css` (متغيرات CSS عامة) + `brand.css`.

### الألوان المحايدة والهوية

| الرمز | القيمة | الاستخدام |
|---|---|---|
| Ink / Navy | `#0B0F1A` | النص الأساسي والسطح الداكن |
| Indigo الأساسي | `#6366F1` | الهوية والتفاعل الرئيسي (CTA، روابط نشطة) |
| Indigo الداعم | عائلة `#6366F1` (فاتح/غامق) | حالات hover/focus |
| Mint الثقة | أخضر نعناعي هادئ | درع الثقة، حالات النجاح |
| Canvas الفاتح | خلفيات فاتحة `#F8FAFC`-grade | الوضع الفاتح |

### ألوان الخدمات الجوهرية (Jewel Tones)

كل خدمة تحمل خيطًا لونيًا خاصًا يُفعّل بسمة `data-service` على جذر مساحتها:

| الخدمة | الخيط | الاستخدام المسموح |
|---|---|---|
| اسأل | نيلي | شارة الخدمة، تدرّج العنوان، حلقة الملقّن |
| تعلّم | أخضر جوهري | كذلك — بلا امتداد للخلفيات الكبيرة |
| ابحث | أزرق جوهري | 〃 |
| أنشئ | بنفسجي جوهري | 〃 |
| برمج | زمردي | 〃 |
| حلّل | ذهبي جوهري | 〃 |
| استكشف | تركوازي | 〃 |

**قاعدة الانضباط:** لون الخدمة يظهر في ≤ 10% من مساحة الشاشة — شارات وحلقات وحدود وخطوط واصلة. يُمنع ملء بطاقة كاملة بلون خدمة أو تعميمه على الأزرار الرئيسية (الرئيسي دائمًا Indigo الهوية).

### الثيمات

| الثيم | السطح | النص | ملاحظة |
|---|---|---|---|
| فاتح (أساسي) | Canvas فاتح | Ink داكن | التسويق وكل الصفحات |
| داكن متوهج | Navy `#0B0F1A` | فاتح `#F1F5F9` | بوابات الخدمة (focus canvas) + تبديل عام |

التبديل عبر `data-theme` مع `next-themes` — لا قيم مضمّنة (hardcoded) خارج المتغيرات.

## 3. الخطوط — الطباعة

| الدور | الخط | الاستخدام |
|---|---|---|
| العربية | **Tajawal** (أساسي) / **Alexandria** (عناوين) | كل النصوص العربية |
| الإنجليزية | **Inter** | كل النصوص اللاتينية |
| الأرقام والمعرّفات | **IBM Plex Mono** | run IDs، تكاليف، أسماء تقنية |

قواعد قياس العربية (إلزامية — NFR-8.7):

| الخاصية | القيمة | أين |
|---|---|---|
| ارتفاع سطر النص | **1.7** | المتن كله |
| ارتفاع سطر العناوين | **1.4** (RTL) | `page-title` |
| تتبّع الحروف العربية | **صفر** | كل العناوين العربية |
| ارتفاع سطر التسويق | 1.55 | بطل الهبوط |

**الاتجاه:** التصميم يؤلَّف RTL أولًا. كل خاصية اتجاهية تستخدم الخصائص المنطقية (`margin-inline-start`, `inset-inline`) — يُمنع `left/right` فيمَا عدا أصول نادرة موثقة.

## 4. المسافات والإيقاع — قوانين الأعداد

| القانون | القيمة | النطاق |
|---|---|---|
| **قانون الإيقاع** | فجوة 48px موحّدة بين الأقسام المتراكبة | كل صفحات ops (`--mj-gap-block`) |
| **سلّم الحاويات** | 480 · 560 · 720–1040 · 840 · 900 | انظر IA §5 |
| **حشوة البطاقة** | قيمة واحدة لكل سطح (`mj-surface`) | بلا انحراف 15/16/17px |
| **الحد الأدنى للمس** | 44px | كل هدف تفاعلي |
| **نصف القطر** | موحّد من `mj-surface` | بلا زوايا حادة جديدة |

**قانون السطح الموحّد:** كل بطاقة موروثة تعاقب واحدًا: حشوة واحدة، نصف قطر واحد، حد واحد، ظل واحد. إضافة «نمط بطاقة» جديد يتطلب قرارًا هنا أولًا.

## 5. المكونات — المسرد المرجعي

المكونات المشتركة الحاكمة (تعريفاتها في `layout.css` / `shell.css` / `workspaces.css`):

| المكوّن | الفئة | القواعد الصاعدة |
|---|---|---|
| زر رئيسي | `.button--primary` | خلفية Indigo داكنة، نص فاتح، CTA واحد لكل شاشة |
| زر ثانوي | `.button--outline` | حد + شفاف |
| زر هادئ | `.button--quiet` | نص فقط |
| شارة | `Badge` | `tone`: success/warning/neutral — خلفية شفافة + نص داكن |
| حبة إتاحة | `.afford-pill` | معنونة بنص لا بأيقونة صامتة |
| بطاقة أداة | `.service-toolbelt` | قابلة للاختيار `aria-pressed` + `is-on` |
| الملقّن | `.workspace-composer` | إطار متدرج يشتعل عند `:focus-within` |
| مسار رباعي | `.service-path` | عقد مرقمة 01–04 + خط واصل + `is-complete` |
| صفحة عمليات | `.ops-page` | رأس → شريط أدوات (`flex: 0 1 auto`) → محتوى، إيقاع 48px |

## 6. الحركة والتفاعل

| النمط | القاعدة |
|---|---|
| مدة الانتقال | 150–250ms — لا أطول في الواجهات التشغيلية |
| منحنى | ease-out للدخول · ease-in للخروج |
| الظهور | تدرّج شفافية + إزاحة ≤ 8px — بلا قفزات |
| الاحترام | `prefers-reduced-motion` يوقف الديكور الحركي |
| المنصة | Framer Motion للتسلسلات المعقدة فقط، CSS للباقي |

## 7. الممنوعات — قائمة الرفض التلقائي

1. **تدرجات بنفسجية معتادة** (نمدي linear-gradient بنفسجي/أزرق عام) — التدرج الوحيد المسموح إطار الملقّن وخيط العنوان بألوان الخدمة.
2. **أيقونات صامتة** — كل زر يحمل أيقونة فقط بدون نص يُرفض (استثناء: أزرار شريط الأوامر القياسية بـ `aria-label`).
3. **ظل بدون وظيفة** — الظل يعبّر عن قابلية النقر أو الارتفاع، لا يُضاف «للجمال».
4. **كثافة نصية عربية بلا هوامش** — أي سطر عربي ملتصق الحواف يُرفض.
5. **لون مشبع في مساحة كبيرة** — انظر قاعدة الانضباط §2.
6. **إضافة CSS محلي داخل مكوّن** — القيم الجديدة تدخل طبقات `styles/universal/*` مع توثيق هنا.
7. **أرقام لاتينية مختلطة بالنص العربي** بلا `IBM Plex Mono` في السياقات التقنية.

## 8. سير عمل أي تغيير بصري

1. **ورقة القرار أولًا:** ما المشكلة البصرية؟ أي قانون أعلاه ينتهكها/تخدمها؟
2. **التعديل في طبقة النظام** (توكنز/مكوّن) لا في نسخة صفحة.
3. **بوابة تحقق بالمتصفح:** لقطات قبل/بعد عند 390/768/1440/1920 + ثيمان + اتجاهان.
4. **مراجعة بصرية مقابل هذا الملف** — أي انحراف يُعد عيبًا لا «ذوقًا».
5. **تحديث هذا الملف** ضمن الكوميت نفسه إذا تغير قانون أو قيمة.

هذا السير مستوحى من مهارة التصميم المرفقة في المستودع `.claude/skills/design-visual-frontend/` — وهي تبقى المرجع التفصيلي لبروتوكول المراجعة البصرية، وهذا الملف هو ملخصها المعتمد على مستوى المنتج.
