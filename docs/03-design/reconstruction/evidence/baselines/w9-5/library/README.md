# W9-5 Baseline (الجزء الأول: مكتبتي) — الصفحة المنسية تُرقّى لتشريح §4.5

> **الموجة:** W9-5-م3/مكتبتي — البند الأول من موجات الصفحات (المرشح «الصفحة
> المنسية» منذ W9-0: آخر تحديث 09-21). النطاق: تطبيق تشريح بطاقة الوسائط الموحد
> §4.5 على شبكة مكتبتي. **التاريخ:** 2026-09-27.

## ما نُفّذ (CSS فقط فوق البنية القائمة — صفر مس ببنية الصفحة)

| عنصر §4.5 | قبل | بعد |
| :--- | :--- | :--- |
| هيكل البطاقة | block عادي | flex عمودي + **min-height موحد 320px** لكل بطاقات الشبكة |
| العنوان | سطر واحد مقطوع `text-overflow: ellipsis` (العناوين العربية تُبتر بصمت) | **line-clamp: 2** + `text-wrap: balance` + min-height سطرين |
| الوصف | بلا حد (تمدد حر) | **line-clamp: 3** + min-height ثلاثة أسطر |
| التذييل | يتبع المحتوى (يطفو فوق مع القِصَر) | **مثبت أسفل البطاقة** عبر `margin-block-start: auto` — نفس خط الأساس في كل صف |
| الحشوة | 15px | 20px (`--mj-space-300`) بموازنة رأسية أخف |
| رفع hover | حدود + ظل فقط | حدود + ظل + **إزاحة −2px** (هدوء، ضمن `@media (hover:hover)` فقط) |
| وضع list | — | **معفى من min-height** (صفوف مدمجة 149px، عنوان clamp-1، وصف clamp-2) |
