## اكتشافان يُرفعان لـ W9-3 (لا يعيقان W9-1)

1. **HIE-01 census = قيمتان الآن** (34px عنوان الصفحة المعياري + 38px hero صفحة «لك»
   من W8-1): المسبار لم يُشغّل منذ W-6 فلم يُرصد ظهور القيمة الثانية. القرار المطلوب
   في W9-3: اعتماد hero البطولة كاستثناء موثق أو توحيده بالسلّم.
2. **ديون راتشا G-7 الموروثة** (spacing/shadows من W-7/W-8): تحتاج موجة سداد
   مستقلة أو إعادة تعيين أساس معتمد بعد W-8 — قرار توثيقي لـ W9-3.
