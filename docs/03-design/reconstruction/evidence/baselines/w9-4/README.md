# W9-4 Baseline — تفاصيل Service Workspace الحيّة (Bible §5)

> **الموجة:** W9-4 من مرحلة W-9. النطاق: رفع تفاصيل §5 الثلاث على السطح المنتجي
> لـ ServiceProductShell (فوق بنية W7-3/W7-4 القائمة): مراحل pills بأربع حالات ·
> عمود مخرجات لاصق 420px · شريط حالة لاصق 40px. **التاريخ:** 2026-09-27.

## مبدأ التنفيذ (لا كسر لبنية W-7)

W-7 وضعت كل أدوات المحاكاة خلف «باب وضع التجربة» — السطح المنتجي نظيف بلا chrome.
**W9-4 تضيف الطبقة الحيّة**: العناصر الثلاثة تظهر على السطح **فقط أثناء وجود
تشغيل** (status ≠ null) — الخدمة الخاملة تبقى نظيفة تماماً (مقيس: L-5). عناصر
التحكم الكاملة تبقى خلف الباب كما اعتمدها المالك.

يقود تشغيلاً حقيقياً عبر السطح المنتجي (تعبئة brief تعلّم → باب التجربة → ابدأ →
عودة للسطح) ثم يقيس الثلاثة + التحكم السلبي.

| الفحص | النتيجة |
| :--- | :--- |
| L-1 شريط المراحل على السطح | 8 pills: done×5 + active + pending×2 |
| L-2 الصبغة + spinner + 32px | bg خدمة rgb(241,236,253) · 32.0px |
| L-3 الشريط اللاصق | 40.0px · sticky · نقطة نابضة + mono |
| L-4 عمود المخرجات | sticky · 420px · فاصل 1px |
