# سجل التغييرات — إعادة البناء v2.0
## «Luminous Premium» — توحيد التصميم وإصلاح شامل

---

## الملخص

أُعيد بناء الطبقة البصرية لمنصة منسج بالكامل: نظامان تصميميان متضاربان (أخضر قديم + بنفسجي جديد) أُلغيا لصالح نظام واحد فاخر، وأُصلحت كل المشاكل المكتشفة في تدقيق بصري شمل 20+ صفحة عبر المتصفح.

## 1. توحيد نظام التصميم

### قبل
- **نظامان متضاربان**: `globals.css` (1977 سطر، هوية خضراء forest/teal) للصفحات الإدارية، و`universal.css` (3612 سطر، هوية بنفسجية luma) للقشرة والتسويق — أي أن المستخدم يرى **موقعين مختلفين** في منتج واحد.
- 152 صنف CSS ميت و242 قاعدة غير مستخدمة.
- نصوص بحجم 8–9px (غير مقروءة).
- حقول إدخال بحواف حادة `border-radius: 0`.
- ظلال رمادية مسطّحة.

### بعد
- **نظام واحد** «Luminous Premium»: `foundations.css` مصدرًا وحيدًا لكل التوكنز (ألوان، هندسة، ظلال، حركة).
- **جسر توكنز** يعيد تعيين أسماء النظام القديم (`--teal`، `--forest`…) إلى القيم الجديدة — فانتقلت ~450 مكوّنًا قديمًا للهوية الجديدة دون إعادة كتابة.
- حذف القواعد الميتة، رفع الحد الأدنى للخط إلى 10px، حواف ناعمة (8–30px)، ظلال طبقية ملوّنة.

## 2. القشرة الجديدة (Obsidian Shell)

- شريط جانبي **داكن فاخر** متعدد الطبقات: تدرّج حبري + توهجات شعاعية بنفسجية/سماوية + نمط شبكي خافت.
- عنصر نشط بإضاءة جانبية متوهجة + تدرّج بنفسجي + حد داخلي.
- بطاقة «ابدأ شيئًا جديدًا» زجاجية بتوهج.
- شريط علوي زجاجي (`blur + saturate`) وأهداف لمس 44px.
- لوحة أوامر (⌘K) وحواريات بإطلالة عائمة وظهور مرن.
- حركة دخول للمحتوى عند كل تنقل بين المسارات.

## 4. التجاوب

- تدقيق بصري فعلي على **1440px و390px** لكل الصفحات (24 لقطة + تحليل آلي).
- شريط تنقل سفلي للجوال مع مراعاة `safe-area` (نوتش آيفون).
- سحب القائمة الجانبية على الجوال بخلفية معتمة + blur.
- لوحة الأوامر تتحول لورقة سفلية (bottom sheet) على الشاشات الضيقة.
- شبكات تتدرج: 4 → 3 → 2 → 1 أعمدة + صفوف أفقية بنقاط تثبيت (scroll-snap) للبطاقات على الجوال.
- فحص فائض أفقي: صفر في كل المقاسات.

## 5. الحركة والتفاعل

- **ScrollFx**: ظهور الأقسام عند التمرير بتدرّج متتابع (stagger 60ms) — دون أي وميض SSR.
- تدرّج العنوان الرئيسي ينساب ببطء (gradient drift).
- هالات الـ Hero «تتنفس»، البطاقات العائمة تنجرف بلطف.
- كل زر: رفع عند hover، انكماش زنبركي عند الضغط.
- كل شيء يتوقف كليًا تحت `prefers-reduced-motion`.

## 6. الوصولية

- ملامح تركيز موحّدة ببنفسجي واضح.
- تباين النصوص مرتفع إلى AA في العناصر التفاعلية.
- الحواريات Radix (تركيز محبوس، إغلاق بـ Escape).
- `prefers-contrast: more` + `forced-colors` مدعومان.

## 7. الجودة

- ESLint: **صفر أخطاء** (كانت هناك تحذيرات).
- TypeScript صارم يعمل عبر الحزم.
- lint يستثني مجلدات النسخة الأصلية والتدقيق.

- `docs/PRD.md` — متطلبات المنتج الكاملة.

# سجل التغييرات — المرحلة 3
## إعادة بناء معمارية التخطيط المتجاوب (Responsive Layout Architecture v3)

### المشكلة البنيوية
كانت الواجهة على الهاتف تبدو كنسخة Desktop مضغوطة داخل شاشة صغيرة: شبكات ثابتة متعددة الأعمدة (5 أعمدة ≥920px)، قشرة ثلاثية الأعمدة (builder-shell/flow-editor-shell تحتاج ≥874px)، جداول بيانات مضغوطة، وعناصر `min-width: 780px`، والحلول السابقة كانت Media Queries ترقيعية لكل عنصر.

### الحل المعماري — 5 طبقات

1. **نظام نقاط توقف موحد** (`src/lib/viewports.ts` + `useViewportMode`): مصدر واحد للحقيقة بين JS وCSS — موبايل <768، تابلت 768–1023، ديسكتوب ≥1024، عريض ≥1440.

2. **بدائل تخطيط جوهرية** (`layout.css` — جديد): `.mj-grid` بشبكات `auto-fill/minmax` ذاتية التدفق (تختار عدد الأعمدة حسب المساحة المتاحة — بدون أي Media Query)، `.mj-split`، `.mj-cluster`، `.mj-data-list` (جدول→بطاقات)، `.mj-scroll-x`. مقاييس `clamp()` سيّالة للفراغات والخطوط.

3. **Container Queries بدل Media Queries**: كل صفحة تعلن نفسها حاوية (`.ops-page`، `.service-space`، `.adaptive-home`، `.universal-library`، `.mj-flow`) — المكونات تترتب حسب **المساحة الفعلية المتاحة لها** (بعد خصم الـ Sidebar) لا حسب عرض الشاشة الخام. السلوك متطابق بين الصفحات عند نفس العرض الفعال.

4. **قشرة بثلاث حالات** (shell.css + app-shell.tsx مُعاد كتابتهما Mobile-First):
   - **موبايل**: Sidebar خارجة للوحة (Off-canvas Drawer) + Overlay + شريط تبويب سفلي + قفل تمرير.
   - **تابلت**: أيقونات Rail (76px) افتراضيًا، والتوسيع يفتح **طبقة فوق المحتوى** لا تدفعه.
   - **ديسكتوب**: Sidebar كامل (264px) يدفع المحتوى، قابل للطي إلى Rail مع حفظ التفضيل.

5. **إصلاح من المصدر**: حذف كتل Media Queries الترقيعية (1220/1040/840/680/430) واستبدالها بأربعة نطاقات Container نظيفة. الجداول (Team/Usage/Sources/Runs) تتحول إلى بطاقات مكدسة بحقول label-over-value عند الضيق. الشبكات (stats/مكتبات/كتالوجات) ذاتية التدفق.

### إصلاحات حرجة مصاحبة
- عناصر `position: fixed` داخل حاويات (`contain: layout`) نُقلت إلى `document.body` عبر createPortal: DemoToast، FeedbackToast، StopButton — وإلا لانحبست داخل الحاوية.
- أهداف اللمس: كل checkbox وزر تبديل ≥44px.
- Topbar موبايل: صفّان (سياق + بحث بعرض كامل) يتوسعان لصف واحد عند ≥768.
- توكنات المواءمة: `--u-sidebar` و`--u-page-gutter` أصبحت aliases للنظام الجديد — لا انحراف هندسي.

### نتائج التحقق (متعدد الشاشات)
- **105 اختبارات** (15 صفحة × 7 مقاسات من 375 إلى 1920): **صفر تجاوز أفقي**.
- مراجعة بصرية آلية (VLM) قبل/بعد: صفحة البحث من «جدار نصوص مضغوط» إلى تخطيط موبايل حقيقي؛ الجداول إلى بطاقات.
- إغلاق Drawer عبر backdrop/تنقل/Escape يعمل؛ طي الديسكتوب يُحفظ في localStorage.
- RTL مُتحقق في الاتجاهين (ar/en): الـ Sidebar على اليمين في RTL واليسار في LTR.
- ESLint: صفر أخطاء. لا أخطاء Console أو صفحة.

# سجل التغييرات — المرحلة 4
## تصحيح تغليف حرج (v4) — تفعيل طبقة التخطيط في الحزمة المسلَّمة

### العيب المكتشف
في حزمة v3 السابقة كان الملف `layout.css` (طبقة بدائل التخطيط الجوهرية: `.mj-grid` و`.mj-split` و`.mj-cluster` و`.mj-data-list`) **موجودًا داخل الحزمة لكن دون سطر الاستيراد الخاص به في `universal.css`** — أي كود غير مفعّل. السبب: أداة المزامنة نسخت نسخة قديمة من `universal.css` (قبل إضافة الاستيراد) إلى مجلد التغليف. خادم التطوير المحلي كان يعمل على المصدر الصحيح، لذا اجتازت كل الاختبارات دون أن يظهر العيب في الحزمة نفسها.

### الإصلاح
- إضافة `@import "./styles/universal/layout.css";` إلى `src/app/universal.css` مباشرة بعد `foundations.css` — لتصبح سلسلة التحميل: foundations ← **layout** ← marketing ← shell ← home ← workspaces ← library ← responsive ← motion ← workbench.
- مطابقة مجلد التسليم مع المصدر **بايتًا-بايت** (diff كامل): صفر فروقات عدا ملفات مقصودة الاستبعاد.
- تنظيف ملفات ميتة من التسليم: `use-mobile.ts` و`use-toast.ts` (غير مستخدمَين في أي مكان) و`original-globals.css` (نسخة احتياطية للتطوير فقط).
- تأكيد أن `tailwind.config.ts` القديم (إرث v3 غير محمَّل في Tailwind v4) وحزمة `packages/config` الفارغة مستبعدان عمدًا.

### نتائج إعادة التحقق
- تثبيت نظيف للحزمة + تشغيل مستقل على منفذ منفصل: كل المسارات تستجيب 200.
- إثبات تحميل طبقة التخطيط: قواعد `mj-grid` تظهر في الـ CSS المُجمَّع وتُطبَّق على العناصر (شبكات auto-fill فعلية).
- فحص ثلاثي الشاشات (375 / 768 / 1440): صفر تجاوز أفقي، الـ Drawer الجانبي وطبقة Rail والـ Sidebar الكامل جميعها تعمل.

# سجل التغييرات — المرحلة 5
## إصلاح طبقات التراكب والقائمة الجانبية (v5) — معالجة جذرية على مستوى النظام

### الأخطاء المبلَّغة (من لقطات المستخدم بالدوائر الحمراء)
1. **الجوال — «أدوات متقدمة»**: توسيع القسم داخل الـ Drawer يجعل عناصره تتراكب فوق قسم الحساب في الأسفل.
2. **الجوال — نوافذ منصة العمل**: بطاقة «تخزين تجريبي محلي» تُرسم تحت شريط التبويب السفلي فيبدو مقطوعًا.
3. **الجوال — إشعار عائم**: دائرة الإشعار البنفسجية تغطي المحتوى وشريط التبويب.
4. **سطح المكتب**: لا يوجد زر طي ظاهر للقائمة الجانبية (كان موجودًا لكن مدفونًا أسفل القائمة خلف حدود الشاشة).

### التشخيص الجذري (بالقياس المباشر في المتصفح)
| الجذر | القياس قبل الإصلاح |
|---|---|
| `.universal-shell-nav` بلا `overflow-y` رغم أنماط شريط التمرير الجاهزة | المحتوى 712px داخل حاوية 553px → يفيض فوق الـ profile (تأكيد: regionBottom 850 > profileTop 691) |
| `.u2-overlay` و `.u2-overlay__content` بلا z-index (auto) | شريط التبويب (z-50) يرسم فوق النافذة؛ العنصر الأعلى عند حافة النافذة = شريط التبويب |
| `.u-feedback-toast` مثبت عند 18px من الأسفل | فوق شريط ارتفاعه 78px — يغطي عناصره |
| زر الطي في أسفل القائمة عند y=842 من إطار 900px | خارج مجال الرؤية المريح — غير قابل للاكتشاف |
| `.command-overlay` (صفحات الأعمال) z-50 = شريط التبويب | الشريط يرسم فوق خلفية النافذة المعتمة |

### الإصلاحات (نظامية — تنعكس على كل الصفحات تلقائيًا)
1. **القائمة تتمرر داخليًا**: `.universal-shell-nav { overflow-y: auto; overscroll-behavior: contain }` — القسم السفلي (الحساب) يبقى دومًا مرئيًا في كل الأوضاع (Drawer/Rail/Expanded)، والتوسيع يدفع المحتوى داخل مسار التمرير لا فوق العناصر. مع `scrollIntoView` تلقائي للعناصر المكشوفة حديثًا.
2. **سلّم z-index موحّد وموثّق** (shell.css): 45 topbar · 50 tab-bar · 55 backdrop · 60 sidebar · 70 notifications · 95 stop-pill · 100 scrims · 101 dialogs/command · 110/111 adaptive · 120/121 workbench · 140 toast · 200 skip-link.
3. **نوافذ منصة العمل**: `z-index: 120/121` + `100dvh` بدل `100vh` (سلوك صحيح مع أشرطة المتصفح الديناميكية).
4. **نوافذ الصفحات الإدارية**: الحواريات `z-101` وخلفياتها `z-100` — فوق الشريط تمامًا مع تعتيم موحّد.
5. **العناصر العائمة تحترم شريط التبويب**: احتياطي `--mj-tabbar-reserve` أصبح على `:root` (ليصل إلى العناصر المنقولة عبر portal خارج القشرة) — الـ toast وstop-button وdemo-toast تطفو فوق الشريط بفجوة بدل الجلوس فوق أيقوناته.
6. **زر طي/توسيع علوي للقائمة**: في رأس القائمة بجانب الشعار (Expanded) وتحت الشعار (Rail) — بمرآة أفقية للـ RTL، بحفظ التفضيل، وبإخفاء الزر النصي القديم المدفون. على الجوال يبقى زر الإغلاق X (لا معنى للطي في Drawer).

### نتائج التحقق
- **63/63 فحصًا** (21 صفحة × 3 شاشات 375/768/1440): صفر تجاوز أفقي، والأوضاع صحيحة (drawer/rail/expanded).
- القياسات بعد الإصلاح: `regionOverlapsProfile: false` · نافذة العمل `topElement = dialog` فوق الشريط · الـ toast يطفو بفجوة 30px فوق الشريط.

### ثانياً: نظام حالات UX (PRD UX-003 / DoD 2-5)

### ثالثاً: إصلاح سباق الترطيب (مكتشف أثناء العمل)
